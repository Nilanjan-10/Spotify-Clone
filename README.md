# 🎵 Spotify Clone

My first web development project, inspired by Spotify's music streaming platform. Built using HTML, CSS, and Bootstrap to practice frontend development fundamentals.

## 🚀 Technologies Used
- HTML5
- CSS3
- Bootstrap

## ✨ Features
- Spotify-inspired user interface
- Navigation sidebar
- Music library section
- Music player interface
- Responsive layout using Bootstrap

## 📚 What I Learned
- Understanding HTML page structure.
- Styling web pages using CSS.
- Using Bootstrap components and layouts.
- Building a frontend project from scratch.
- Improving my understanding of responsive web design.

## 🎯 About the Project

This was my first project in my web development journey. It helped me build a foundation in frontend development and motivated me to explore more technologies and build bigger projects.
